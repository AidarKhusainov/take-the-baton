# Private Take the Baton installation registry

Use this template outside work checkouts. See UPDATE.md in the Take the Baton source for maintenance and discovery rules. Keep one entry per verified installation on this host. The registry helps find installations. Verify the profile and actual activation route before applying an update.

Keep all known startup routes in the same installation entry. For each route, retain its worktree or scope, rule and instruction path or manual route, and its last verified revision and pending status if applicable. Keep unavailable routes until reconciled.
