# Take the Baton

[English](README.md)

«Разберись с задачей, внеси правку и открой пул-реквест». С Take the Baton агент выполняет согласованные шаги и задаёт конкретный вопрос, когда нужно твоё решение. Если работу предстоит продолжить в новом чате, он оставляет запись с изменениями, результатами проверок и следующим шагом.

## Как начать

Открой чат с агентом в своём проекте и отправь этот запрос.

```text
Подключи Take the Baton к этому проекту.
https://github.com/AidarKhusainov/take-the-baton
```

Если при настройке выбрал ключевое слово `эстафета`, начни с него запрос.

Чтобы разобраться в задаче:

```text
Эстафета: изучи PROJ-123
```

Чтобы довести задачу до пул-реквеста:

```text
Эстафета: разберись с задачей PROJ-123, внеси правку и открой пул-реквест.
```
